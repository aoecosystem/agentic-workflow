4. Indexes Strategy

One row per index. Cover the queries that drive screen performance — search, filters, joins, sort orders.

Index nameTableColumnsQuery pattern it serves
{{idx_name}}{{table}}{{col_a, col_b}}{{e.g. "list bookings by provider, ordered by start_at"}}
{{idx_name}}{{table}}{{...}}{{...}}

Rules of thumb

  • Index every foreign key.
  • Index every column used in WHERE with high selectivity.
  • Composite index when the query uses multiple columns together (in the same order as the index).
  • Partial indexes for sparse data (WHERE status = 'active').
  • Avoid over-indexing — every index slows down writes.
