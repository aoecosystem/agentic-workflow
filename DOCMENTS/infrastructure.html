8. CI / CD Pipeline

▾

Pipeline stages

  1. Lint & typecheck — runs on every push.
  2. Unit tests — runs on every push.
  3. Integration / E2E tests — runs on PR + main.
  4. Build artifacts — frontend bundle, backend container.
  5. Deploy to dev — auto on merge to main.
  6. Deploy to staging — manual approval after dev passes smoke tests.
  7. Deploy to production — manual approval after staging is green for 24h.
CI provider{{GitHub Actions | GitLab CI | Vercel | provider}}
Required GitHub secrets{{DATABASE_URL, DEPLOY_TOKEN, ...}}
Branch protection{{require 1 review + green CI on main}}
Rollback strategy{{revert merge + redeploy | provider one-click rollback}}
